# Muhammad Zahid — Portfolio

A bilingual portfolio for Muhammad Zahid, presenting software development, cloud automation, and Urdu and English editorial design work.

## Highlights

- English and Urdu content with a language toggle
- Responsive project cards and accessible project detail dialogs
- Selected page samples from *Tazkia Book 4*, optimized as WebP images
- Contact form that prepares a message in the visitor's email app
- Privacy and terms information within the site

## Built with

React, TypeScript, Vite, Tailwind CSS, and Motion.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. Install project dependencies:

   ```sh
   npm install
   ```

3. Start the development server:

   ```sh
   npm run dev
   ```

4. Open the local address printed by Vite (by default, `http://localhost:3000/`).

Create a production build with `npm run build`; preview it locally with `npm run preview`.
